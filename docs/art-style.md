# 青丘灵录｜美术规范

> 仓库和 ChatGPT 美术项目共用这一份。改规范时两边一起改。

## 整体风格
2D 国风 Q 版，明亮温暖，干净线条，柔和阴影，光源统一在左上方。
全部原创设计，不得模仿梦幻西游、大话西游或任何现有游戏的角色、怪物、图标。

## 配色
- 主色：青玉绿、暖金色、米白色
- 点缀：朱红色（绳结、印章、警示）
- 避免：高饱和荧光色、大面积暗色

## 角色与宠物
- 头身比 2~3 头身，圆润可爱，大眼睛
- 视角：斜 45 度俯视，默认朝左上方站立（敌方由程序水平翻转）
- 全身完整、脚底着地、纯白背景，不要地面阴影（阴影由程序画），不要文字和水印
- 野生和宝宝共用同一造型；宝宝只在名字后缀加「宝宝」；变异由程序调色，不另画图

## 场景背景
- 仙侠山水：云雾、瀑布、远山楼阁、花树
- 横屏 1334×750 构图，中间留出平坦空地给战斗站位
- 远景淡、近景清晰，不抢角色的视觉焦点

## UI 图标
- 圆形徽章：青玉色底、金色细边框、底部金色云纹，中间一个简洁的金色符号
- 不写字（文字由程序加）
- 多个图标在一张图里排成网格，大小一致，纯白背景
- 禁用状态不另画，由程序调灰

## 出图规则
1. 每次出图附上参考图，保持一致的风格、线条粗细、配色和光泽。
2. 同类素材尽量一次在一张图里批量出。
3. 不确定的地方先问，不要自行添加设定。
4. 每张图说明用途和建议文件名（英文小写加下划线，如 pet_tingwa、icon_auto）。
5. 新图和旧图拼在一起对比，不统一就重出。

## 交付与处理（由 Codex 负责）
- GPT 原图放 `art-source/`，不进游戏包
- 处理后放 `assets/textures/`：去白底、裁空白、统一尺寸、底部对齐、压缩
- 单位图：256×256 画布，底部居中对齐，锚点 (0.5, 0)
- 图标：128×128；背景：1334×750 JPG，尽量 300KB 以内
