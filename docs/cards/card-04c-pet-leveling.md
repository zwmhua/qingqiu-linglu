# 青丘灵录｜卡 04c：召唤兽升级与潜能分配

**状态：策划终稿 v1.0｜未授权开发。**  
**前置：** 卡 03a、03b 已经华周试玩通过；**04a、04b 也必须先逐卡试玩通过**，尤其 04b 通过后才能单独授权 04c。  
**目标：** 出战召唤兽领取完整胜利经验，升级后五项各 +1、另获得 5 潜能，玩家在原详情使用与人物一致的预览/确认/取消；成长进度与个体资料刷新不丢失。  
**风险：qa**（召唤兽进度本地读写、确认加点、测试重置）。

## 一、范围与玩家看到的效果

1. 抓回来的怪就是召唤兽，不新增其他宠物身份体系；沿用卡 02/03 的物种、个体 ID、普通/宝宝、变异、六资质、成长、携带上限与召唤功能。
2. 初始两只均为独立随机 **1～5 级普通野生汀蛙**，各自五项按 `50+10N` 规则随机分配好（每项至少 1）、初始潜能 0；各自战斗面板用汀蛙临时公式，不使用旧 `38/11/10/10`。这两只已在 04a 初始化，本卡不得刷新时重复生成。
3. 新抓野怪保留**抓取时真实等级、五项、六资质、成长、宝宝/变异身份**，同级经验从 0 起、进入携带时未分配潜能为 0，不能重新掷出另一个个体。
4. 采用**04a 唯一经验表及每场奖励**：战斗开始时锁定敌方名单、胜利每敌 `8+2×有效等级` 相加、失败 0；已抓敌计入经验、不另外奖励；一场只发一次。人物得全额，本场每只**实际出战过**的召唤兽也各得全额（倒地/换下仍算），仅携带未出战不得经验；重复召唤不重复得；本场刚抓的必须真的出战才有本场经验。
5. 召唤兽每升一级五项**各 +1**，另获得 **5 点潜能**；0 级宝宝首次 0→1 从五项合计 50 变为 55、未分配潜能由 0 变为 5；保留宝宝/变异身份，不额外随机给 10 点，不重掷五项/资质/成长。溢出经验可连续升级，20 级封顶且不累计超额经验。
6. 在原**召唤兽详情**保留物种名称、身份、六资质、成长、召唤操作，补全**等级、升级经验（本级当前/所需）、五项基础属性、剩余潜能、五项 `＋/－`、确认、取消**。交互与 04b 的人物加点一致：预览可撤销，确认才保存，取消不生效，允许潜能保留。
7. 升级后战斗使用卡 03 临时面板（适用到 20 级），**只依物种和有效等级变化**。召唤兽五项和潜能加点、六资质与成长暂不影响临时四维；不能偷偷使用人物系数或正式召唤兽公式。
8. 同一只召唤兽的等级、经验、五项、潜能、加点结果、六资质、成长、身份、携带关联保存到浏览器本地。刷新不重掷，测试「重置」会连同人物进度一起清除本游戏数据并重新生成初始两只汀蛙。每场新战斗开始按更新后的最大气血/法力满值进入；升级后补满新上限。

## 二、数值及临时战斗面板（已定）

**等级与点数守恒：** 五项已分配合计 + 未分配潜能 = `50+10×真实等级`。野生 N 级生成时全部随机分完，潜能 0；后续升级不随机分剩余 5 点。

**同一经验表：** `levelUpExp(L)=10×(L+1)`；0→1 为 10，19→20 为 200；并非宝宝独立经验表。

**临时战斗面板：** `d=max(1,level)-1`：

| 物种 | 最大气血 | 攻击 | 防御 | 速度 |
|---|---|---|---|---|
| 汀蛙 | `33+4d` | `10+floor(d/2)` | `9+floor(d/2)` | `9+floor(d/2)` |
| 磐龟 | `45+6d` | `9+floor(d/2)` | `13+d` | `7+floor(d/2)` |
| 毛毛虫 | `26+3d` | `14+floor(d/2)` | `7+floor(d/2)` | `10+floor(d/2)` |

0→1 宝宝真实等级改变、五项和潜能成长，但**战斗有效等级仍为 1，临时四维数值不变**。1→2 以后按临时公式变化；同等级五项加点不同不应造成临时战斗四维差异。

敌方野怪仍为 0 级宝宝或随机 1～5 级野生怪，遭遇数量、变异、资质/成长、抓取等一律沿用卡 03；不随人物或召唤兽等级动态匹配。

## 三、华周一次试玩怎么验收

1. 打开初始两只汀蛙详情：各自等级 1～5、五项合计 `50+10N`、潜能 0，且资质/成长/物种独立、稳定。抓到另一种野怪后打开详情，确认名字、等级、经验 0、潜能 0、原个体资料没被重掷。
2. 带一只召唤兽打赢战斗，详情可看到该只获得完整经验；未出战个体的经验保持 0。连续打至升级，查看**五项各 +1、剩余潜能 +5**；如果升级过程中把它换下或它倒地，但整队赢了，仍按本场出战资格拿全额。
3. 在详情给五项分配潜能：点 `＋` 看五项与剩余潜能预览，点 `－` 可撤回本轮未确认值；点「取消」后原样恢复。再重新分配并点「确认」，关闭、重开详情及刷新网页，已确认点数保留；此前的六资质、成长、宝宝/变异身份不变。
4. 升级后「再来一场」，确认它按对应物种**新等级**临时四维作战；仅给五项加点却不升级时，临时战斗四维仍不变，这是本阶段明确的限制，不算失败。
5. 0 级宝宝 0→1、20 级封顶、不重复结算等较难随机遇到的边界，使用确定性测试样本/测试数据展示法核对：宝宝五项合计 **50→55**、潜能 **0→5**、临时有效等级仍 1；20 级不再涨经验或点数。
6. 切换召唤兽、重复召唤、刷新、重新战斗，不得串经验和个体身份；测试重置必须将全部成长进度清零，人物回 0 级、初始两只汀蛙重新随机。

**试玩判断：** 玩家的确是在培养同一只召唤兽；能清楚看到等级、经验与潜能增长；人物和召唤兽加点操作一致。
