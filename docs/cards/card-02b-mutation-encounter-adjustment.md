# 青丘灵录｜02b 变异判定时机修订（2026-11-11）

华周确认：变异与宝宝一样，在每只野外单位生成时独立判定，出场时身份已固定。本修订覆盖此前任务卡中「抓取成功后判变异」的说明；[25% 概率修订](card-02b-mutation-rate-adjustment.md)仍有效。

- 每只野怪出场时按 `mutation.rate=0.25` 判定一次，普通与宝宝均可变异；初始两只普通汀蛙不参与判定。
- 六项资质先按普通或宝宝区间生成；变异时各乘 1.18、四舍五入、不封顶。成长、五项基础属性和战斗数值不变。
- 抓取成功只复制目标现有身份和属性；抓取失败、目标倒地、倒地改抓均不重新判定。改抓成功保留实际被抓目标的身份。
- 野外变异单位沿用原 SpriteFrame 的程序调色并显示「变异」；受击闪红后恢复该个体颜色，抓获后战场、头像与详情一致。

验收：固定本地变异样本出场即为变异；抓获后携带身份和资质不变；失败与倒地不额外判定。浏览器观察野外颜色、文字和抓取后的颜色延续。
