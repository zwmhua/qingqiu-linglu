# 青丘灵录｜卡 03a｜三种野怪随机遭遇、敌方战斗、抓取与资料

**状态：可交付 Codex 的阶段一执行卡；仅授权 03a，不授权 03b。**  
**总卡依据：** `docs/cards/card-03-three-wild-species.md`，以 `docs/roadmap.md` 和卡 02 后续修订为现行规则。  
**前置：** 卡 02（含 02a、02b-1～6、25% 出场变异修订）已完成并经华周试玩通过；现有战斗、携带与抓取功能保持。

**推荐模型/档位：** GPT-5.1 Codex / Medium。  
**风险标记：** 普通（仅会话内存；不做持久化）。

## 一、目标

每次战斗随机遭遇 1～3 只汀蛙、磐龟、毛毛虫；三种敌人按各自临时面板战斗，玩家可用原有抓取方式捕获，并在现有携带详情里查看**正确物种及该个体的资料**。

**为什么：** 先验证“遇见三种怪、打起来不同、想抓下一只”。己方新宠完整面板与跨战斗战斗表现留 03b，避免一张卡同时排查遭遇与上阵两条路径。

## 二、玩家看到的效果及规则

1. **无选怪环节。** 进入战斗及点击「再来一场」均直接随机遭遇，不增加营地、地图、选怪菜单、保底或指定怪物。每场数量 1/2/3 只分别为 **50%/35%/15%**；每个敌方位置独立等权选择**汀蛙、磐龟、毛毛虫**（各 1/3），允许同物种重复、混合或全同种。
2. **等级与稀有身份。** 普通野生每只独立等权抽 **1～5 级（各 20%）**；每个遭遇单位仍独立按 **5%** 成为 **0 级宝宝**，显示 0 级、战斗有效等级 `max(1, level)`。每个遭遇单位**出场时**按 **25%** 独立判定变异，立即显示变异标记和程序调色；宝宝和变异可以叠加。抓取成功只继承该单位已有身份，失败或倒地改抓均**不重新判定变异**。这是卡 02 的最新规则，覆盖总卡中“抓取成功后再判变异”的旧句。
3. **三种敌人及美术。** 普通敌人显示「野外汀蛙／野外磐龟／野外毛毛虫」，宝宝显示「汀蛙宝宝／磐龟宝宝／毛毛虫宝宝」。汀蛙沿用原图；磐龟、毛毛虫接入已提供的 `pet_pangui.png`、`pet_maomaochong.png` 及其 Cocos SpriteFrame。宝宝暂用同物种野生图，变异只程序调色；不新画素材，不把其他物种的图作为替代。
4. **敌方临时战斗面板：临时，待公式卡替换。** `d = max(1, level) - 1`，所有数值来自配置，不能由六项资质、成长、五项基础属性换算：

   | 物种 | 气血 | 攻击 | 防御 | 速度 |
   |---|---|---|---|---|
   | 汀蛙 | `33+4d` | `10+floor(d/2)` | `9+floor(d/2)` | `9+floor(d/2)` |
   | 磐龟 | `45+6d` | `9+floor(d/2)` | `13+d` | `7+floor(d/2)` |
   | 毛毛虫 | `26+3d` | `14+floor(d/2)` | `7+floor(d/2)` | `10+floor(d/2)` |

   敌方野外 1 级汀蛙仍为 **33/10/9/9**；两只初始 1 级普通汀蛙保持 **38/11/10/10**，本卡不得改变。0 级宝宝按 1 级面板计算，但数据中的等级仍为 0。此处只验收**敌方**面板；03b 再验收己方抓获宠共用公式。
5. **抓取与资料。** 三物种满血基础抓取率均为 **20%**，残血加成、上下限、倒地改抓、携带上限 **5**、召唤及跨战斗携带机制复用现有规则。抓到的宠物保持自身物种身份、宝宝/变异、等级、六项资质、成长、五项基础属性，不能因旧代码写死“汀蛙”而改名或重掷。详情使用当前页面，不增设新展示页。新增物种进入原召唤列表不应报错，物种名称、身份及配图必须正确。**03a 不要求己方新物种战斗数值正确：** 若玩家召唤已抓的磐龟或毛毛虫，只要名称和形象对，战斗面板可以先不对（沿用旧占位也可以）；不要为此打回 03a，也不要在 03a 擅自改成正式属性公式或提前做完 03b。己方新物种战斗面板的完整一致性与持续出战表现由 03b 验收。
6. **三物种资料规则：** 继续使用卡 02 的独立双骰/四舍五入、宝宝取各项上半区间；成长千分位整数抽样、显示三位小数；五项基础属性 0 级合计 **50** 点、普通 N 级合计 **50+10×N** 点、每项至少 1；变异资质 ×1.18 四舍五入、不额外封顶，成长不加成。**复用算法，不复制三套实现。**

## 四、华周怎么验收（一次试玩会话）

1. 打开 Web 预览，**没有地图、营地或选怪界面**；在原战斗界面多玩几场，看到三种不同外观和名称，出现 1～3 只与混合阵容。少量试玩**不用于判断概率是否精确**，概率交给逻辑测试。
2. 战斗中对比同等级敌人的气血与受击/出手：**磐龟更厚、更耐打、更慢；毛毛虫更薄、攻击更高**；野外 1 级汀蛙基线不变，己方初始汀蛙原面板不变。高等级敌人可能较难打，感受单独写试玩日志，03a 不临时改数值。
3. 抓一只磐龟或毛毛虫，在原携带列表点击它：物种名称、等级、六项资质、成长（三位小数）、五项基础属性与普通/宝宝/变异标志均属正确物种。关闭重开详情、再来一场查看，资料不能重掷；原召唤列表不崩溃，名称和配图正确。若把它召唤上场，本卡只验收名称和形象，不验收其战斗数值；数值不对不算 03a 失败。
4. 如遇宝宝，看到 **Lv.0**；如遇变异，**出场就有标记和变异色**，受到攻击后恢复变异原色；抓取后保留对应身份。无需靠手刷验证 5%/25% 的概率边界。
5. 用原先能复现的操作验证：抓取目标在行动前倒地，若另有存活敌人则按既有规则改抓，不能发生空抓；原攻击、防御、保护、召唤及携带满额拒抓仍正常。

**判断是否继续：** 新增物种是否明显不同？抓到磐龟或毛毛虫后是否愿意再抓一只比较？试玩结束记一行：`日期｜03a｜好玩／不好玩／手感不对｜原因`。03a 通过后才启动 03b。
