# 青丘灵录｜02b-6｜变异汀蛙调色与受击恢复

> 后续规则修订：正式变异概率已由 2.5% 改为 25%；本卡下文的 2.5% 保留为执行当时的历史数值。现行规则见 [02b 变异概率修订](card-02b-mutation-rate-adjustment.md)。

## 目标

变异汀蛙在战斗、头像与宠物详情中使用区别于普通汀蛙的程序调色色调，受到攻击后仍恢复变异原色。

**为什么：** 不增加素材就能让玩家一眼认出罕见宠；受击红闪不该把它打回普通颜色。

## 玩家看到的效果与规则数值

- 普通汀蛙与变异汀蛙仍**复用一张汀蛙图片**，只根据 isMutated 标记设置 Sprite 调色；颜色应清晰可辨，具体色值由现有美术风格与表现配置确定，不改变变异随机率和资质。
- 战场立绘、头像与宠物详情统一呈现变异色，文本仍显示「变异」。
- 攻击受击红闪结束时恢复该实例应有的原色（普通恢复普通色、变异恢复变异色），重新渲染、召唤切换、战斗重开均保持。
- 变异概率仍 **2.5%**，六项资质仍是 ×1.18 后四舍五入、不封顶，成长不加成；本卡不得动这些纯规则。

## 华周怎么验收（一轮试玩）

打开 Codex 提供的**本地固定变异样本**：看到变异色与旁边普通汀蛙不同；让变异汀蛙被攻击，红闪后仍是变异色；召唤或重新打开详情，颜色仍正确；原有点击选择、战斗动画与血条正常。

## 可调参数

只涉及视觉色值/透明度等已有或新增 visual 配置，不增加新玩法概率和面板数值；不得额外生成美术贴图。

## 逻辑测试

纯规则部分确认颜色映射由 isMutated 唯一决定，不因受击事件改变身份；必要的 UI/表现回归以真实浏览器试玩为准，自动测试不替代视觉验收；现有抓取、变异、战斗测试通过。
