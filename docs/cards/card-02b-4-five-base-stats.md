# 青丘灵录｜02b-4｜五项基础属性点数生成与展示

## 目标

在既有宠物详情显示体质、法力、力量、耐力、敏捷五项点数，且总点数与宠物等级和类型一致。

**为什么：** 基础属性是「分给这只宠物的点」，六项资质是「这只宠物将来擅长什么」。先让玩家看到区别，暂时不改现有战斗伤害。

## 玩家看到的效果与规则数值

- 五项名称固定为：**体质、法力、力量、耐力、敏捷**，与六项资质分组显示（例如「法力」与「法力资质」分别标明）。
- **0 级汀蛙宝宝**：五项合计 **50** 点；**野生 N 级汀蛙**：合计 **50+10×N**；**初始两只均为 1 级普通汀蛙，每只单独合计 60 点**，**不是** 0 级宝宝的 50 点。
- 每项最低 **1 点**。先给每项最低点数，再将剩余点数以公平随机方式分配到五项；总点数必须精确不变，每项整数，不设置未确认的权重或职业偏向。
- 每只宠物的五项点数仅生成一次，存于对应内存个体；跨详情、抓取、召唤、下一场均保持不变。刷新页面恢复新会话的初始两只，重新初始化。
- 只显示点数及总和，不根据五项换算气血、法力上限、攻击等面板数值。原本的面板数值不变。

## 华周怎么验收（一轮试玩）

打开携带列表，依次查看初始两只：等级均是 1，五项各不低于 1 且**各自总和都是 60**；抓到一只普通 1 级汀蛙再看，总和也是 60。关闭详情并「再来一场」重新打开，原个体五项值不变。0 级宝宝的合计 50 由固定测试样本与逻辑测试核验。

## 可调参数

baseStats.minPerStat = 1；宝宝 0 级总点 50；普通 N 级总点 50+10×N。不得给初始两只另造点数总额。

## 逻辑测试

初始两只每只 60 点且各自独立随机，绝不是 50；0 级宝宝恰好 50；野生 N 级合计 50+10×N；五项都是整数且 ≥1；多次不同种子测试五项均能获得额外点数；同一宠物跨调用、跨战斗不变；不改变现有战斗面板与抓取规则。

## 本卡不做

不加点、不分潜力点、不按五项计算面板、不做技能与升级、不改成长或资质生成规则。
