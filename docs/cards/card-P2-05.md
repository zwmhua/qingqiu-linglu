- **真实目标**　玩家从标题开始或读档先进城，走到野外才可能遇怪，战后带着同一份进度回到地图，再次点地继续探索。

## 2. 玩家体验与规则

从标题点「开始游戏」到城镇出生点，城里随便走都不会开战。出城看不到怪，沿河岸走动才有机会进入现有回合制战斗。胜利、抓走最后一只或整队逃跑回本场触发点。战败回城出生点、气血法力回满。回图即停步，玩家重新点地后才继续行走和累计遇怪距离。

| 项目 | 已确认规则 |
| --- | --- |
| 速度 | 沿用 180 世界逻辑单位/秒，和战斗倍速无关 |
| 保护 | 每次成功进入野外，或胜、抓胜、逃成功返回野外，保护重设为 180 世界单位，同时清空上次检查余数 |
| 抽取 | 保护先消耗，保护期间不累积抽取距离。保护后每满 60 世界单位按 10% 检查一次。首次可能命中在连续走满 240 单位时。未中保留不足 60 的距离，无保底 |
| 一帧过多段 | 按各实际走过的路径段依次过阈值，首个命中就停在该段的命中点，丢弃本帧剩余移动，清掉当前目标和剩余路径，只开一场 |
| 暂停 | 只有野外前台、可操作且没有面板、加载、回城或战斗阻挡时的实际位移才计入。静止、镜头滚动、动画起伏、无效点击、传送及后台不计。开关面板或切后台保留已有保护和余数，停步后需重新点地 |
| 怪物池 | 使用现有区域池与生成规则。汀蛙、磐龟、毛毛虫等权，野生 1～5 级等权，1/2/3 只权重 50%/35%/15%，宝宝 5%、真实 0 级，变异 25%。复用现有配置来源及生成器 |
| 自动战斗 | 野外可开关，暗雷开战使用当前值，战斗中改动供下场使用。回图不自动走，刷新沿用默认关，自动设置不入档 |

距离阈值和概率放在野外区域配置，状态只在本次会话。进入另一地图成功后才切换区域状态，失败仍停在原地图且可重试。角色移动、遇怪抽取和地图切换不写档。刷新回城，进度读取最近成功快照。保留 P2-04 动画后保存、同候选失败重试、战败回城加载失败锁定重试及一次结算。读档失败要明确提示，并保留原档。按已有面板规则处理人物、宠物操作，背包和合宠沿用未开放状态。

按路径段累计有一个玩家能看到的结果：即使掉帧，角色仍停在真正遇怪的位置。按距离保护让玩家回到野外后有一段可以主动走开或回城的路。

## 3. 正式入口与实现范围

- **保留 Boot 的加载边界。** `BootView.ts` 已加载 `battle` Bundle 并运行原 Battle.scene。把该场景在无调试参数的启动行为改成共用会话进城，复用现有 TownView 按需载入 `town`，出城再载入 `outskirts`。普通 Web、微信启动均需走这一入口，不能靠浏览器查询参数启动地图。
- **把正式玩法接到已验收的战斗流程。** `BattleView.ts` 的 `startFixedBattle()`、`finishBattle()` 和 `postBattle` 已具备防重复开战、返回点、同档保存和回场状态。复用一条地图开战路径，触发点是停止后的世界坐标。野外加载成功和战后回野外各重置一次距离保护。正式路径仅靠移动遇怪，战果以系统消息交代。固定开战、样本和旧版直接战斗重开仅允许在明确启用的 Creator 调试路径使用。样本走同一份进度，临时固定判定和遭遇输入。
- **按真实移动接线。** 主线换图插卡后，`TownView` 使用 `scripts/walkable-path.ts` 的 `WalkMovement.update()`，同一帧可以走多个连续段。复用现有路径规划和边界，在提交每段位置时累计实际距离，能在段中命中处截断。保护计算和判定是纯 TS，便于用固定随机序列测试。地图与战斗切换只在位置和镜头已更新到命中点后执行，沿用场景锁和输入拦截。
- **用现有正式地图。** 核对主线 `town` 的 1672×941 城镇街图和 `outskirts` 的 3344×941 野外图、UUID、构建归属及滚屏显示。当前代码已引用两张正式图，本卡按现有资源验收。若实测仍缺图或需要换图，按 X2 报出缺项，由华周提供素材后再定范围。

## 4. 测试与华周试玩

沿用 `node:test`。限定 `tsc` 覆盖改动的纯 TS 和真实传递依赖。增加本卡覆盖，保留 P2-04 结算失败和重试断言。全视图类型检查如仍有基线 `TS2322`，报告同基线核对结果，不从其他通过项推定全视图通过。

1. **纯逻辑**　概率 0 和 1，180 保护边界，保护结束后满 60 才首次抽取，小数余数与帧切分等价。固定随机序列覆盖同一帧多个阈值先失败后命中、余下路程丢弃。多段拐弯大帧与小帧算出同一命中点，停点不被视角换算改变。
2. **真实接线**　城内、传送、镜头、UI、后台、切图和战斗不累计。切入野外失败保留来源，成功重试才初始化保护。面板开关保留已有计数，恢复后不续走。首个命中即停止并且只创建一场。胜、抓胜、逃成功回野外且重新保护，败回城。保存失败不提前回图，重试使用同一结果。正式入口接真实旧档，刷新只读最近成功快照并回城，坏档不被写回覆盖。
3. **验收样本**　提供一个开发预览的确定性遇怪样本或同等可重复方法，说明实际 URL、固定输入和点击位置，让华周能复现最早的 240 单位命中。可复用 P2-04 单敌、两敌、战败样本。样本须明确启用，只影响本场判定，沿用同一存档接口，不写测试参数进档。正式发布配置使用基准 10%，固定开战和样本控制不出现。需要准备存档时，使用华周确认可用于试玩的数据，勿用样本静默覆盖现有资料。

| 从无参数标题开始，先在城内走动，再点「出城」 | 开场在城镇出生点，城里不打仗，已有宠物和经验在。出城后地图跟随角色滚屏，HUD 固定 |
