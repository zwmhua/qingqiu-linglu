# task/37-bag-ui 背包界面（第二阶段简易版）

做出可查看和使用道具的横屏「背包」。使用城里杂货铺、城里背包和野外背包入口。

- 仅支持已有 12 本技能书、还童露和变异还童露。技能书共用书图并叠技能图标，还童露用已有瓶子图标。库存按 itemId 叠一格，数量标在右下角。
- 顶栏显示「背包」，右上角关闭。左侧只展示角色立绘和金币。右侧为固定五列，保留空格，下方说明显示名称、作用、数量和「使用」。未选中提示「点击道具查看」。
- 点击使用后从现有携带名单选宠。打书沿用新增／顶替提示及确认，还童沿用不可逆确认。成功扣除一件，扣至零清空对应格。
- 不启用 pageSize、stackLimit 或翻页，不增加仓库、装备、外观、页签、礼包、整理、出售、丢弃或双击使用。不变更既有打书、还童、掉落规则和数值。
- 可改背包界面、地图入口、相关集成测试。业务与测试合计增删最多 300 行。沿用 inventory 分包及已有素材，原图和带字参考图不进包。只做本地提交。
- 用 ego-browser 实点城野入口及打书、还童，保留未选中、技能书、还童露、使用确认和扣除后的画面。报告提交号与包体变化。
