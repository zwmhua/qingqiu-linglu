# 召唤兽新版面板与放生

从 task/22 的 `85310ab` 开发 task/24。两步各自验收，第一步本地提交后等华周确认。每步的业务代码和测试合计增删上限为 200 行。

## 第一步　新版面板

- 属性和资质技能页共用左侧头像、名称、身份、等级、物种立绘和放生按钮。放生按钮此步仅展示。两张无字底图裁切压缩，运行时绘制文字、数值和条形填充。
- 携带区显示两行五列。点击已占用格查看该只召唤兽，空格不可点。出战格显示红色「战」，查看格用金色框标出。
- 属性页显示气血、法力、经验和伤害、防御、速度、躲避、灵力。属性使用现有正式公式。
- 资质技能页显示六项资质、成长和 12 个空技能格。条长根据物种配置的上下限计算，变异超上限时显示亮色满格。
- 右上角头像仍打开召唤兽面板。右侧「加点」进入现有实时预览页，返回原页签和个体。沿用加点规则与现有携带容量。
- 用 node:test 验证资质条下限、上限、中间及超限。浏览器核对 13 级汀蛙的气血 150、法力 108、伤害 116、防御 45、速度 33、躲避 25、灵力 73，并验证切页、选宠、加点页和返回。

## 第二步　放生（待华周确认第一步）

- 面板内放生需二次确认。战斗中禁用，出战个体不可放生且点击提示原因。
- 确认后直接删除个体，切到剩余第一只，腾出的携带位可继续抓取。放生无奖励。
- 写入现有本地进度，刷新后保留，测试重置可恢复。规则放在 assets/logic，覆盖正常放生、出战拒绝、只剩出战个体和携带数变化。
- 浏览器验证携带满时放生再抓取及刷新持久化。本地提交说明标 qa。
