# 青丘灵录｜02b-1｜0 级宝宝遭遇与身份延续

## 目标

在现有 1～3 只汀蛙战斗中，少量出现「汀蛙宝宝 Lv.0」，能抓到它，并在携带列表、召唤和下一场战斗中保持宝宝身份。

**为什么：** 先让玩家遇到一只特别的汀蛙，不动养成数值系统，验证「偶遇稀有宠」是否带来惊喜。

## 玩家看到的效果与规则数值

- 每个遭遇单位独立以配置的 **5%** 概率成为宝宝；原有 1/2/3 只遭遇权重 **50%/35%/15%** 不变。
- 宝宝名称显示「汀蛙宝宝」，**等级 0**、标识 isBaby=true；普通敌人仍为「野外汀蛙」及其已有等级。
- 敌方宝宝与野外汀蛙共用一张素材，不换图；宝宝 0 级参与战斗时属性计算使用 **max(1, level)**，不引入新的面板公式。
- 抓取概率、速度、伤害、携带 5 只上限不变。抓到后，携带列表、同场召唤、跨战斗均保存原等级及 isBaby；不是因抓成功才变为宝宝。
- 为了不让华周反复刷 5% 概率，提供**仅本地开发预览可用、与正式随机流程隔离**的固定宝宝场景或测试入口；不得改变正常概率。

## 华周怎么验收（一轮试玩）

在 Codex 提供的**测试预览入口**打开战斗：看到「汀蛙宝宝 Lv.0」；使用撷灵客抓住它，打开携带列表能认出宝宝；有敌人剩余时尝试召唤，或打完后「再来一场」再查看，宝宝等级仍为 0。切回正常预览应仍使用 5% 随机遭遇，不变成必出宝宝。

## 可调参数

baby.encounterRate = 0.05；宝宝实际等级 0、战斗有效等级 max(1, level)；遭遇数量权重沿用现有配置。

## 逻辑测试

宝宝随机判定按每只敌人独立执行；固定随机源可覆盖普通与宝宝；宝宝等级始终是 0，战斗有效等级是 1；抓取→携带→召唤→新战斗过程中 isBaby、level 不丢；普通汀蛙不被误标为宝宝；旧战斗回归通过。
