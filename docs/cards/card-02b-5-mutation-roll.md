# 青丘灵录｜02b-5｜变异判定与资质加成

> 后续规则修订：正式变异概率已由 2.5% 改为 25%；本卡下文的 2.5% 保留为执行当时的历史数值。现行规则见 [02b 变异概率修订](card-02b-mutation-rate-adjustment.md)。
> 后续时机修订：变异改为野怪出场时判定，抓取只继承身份；见 [02b 变异判定时机修订](card-02b-mutation-encounter-adjustment.md)。

## 目标

抓取成功后偶尔得到「变异汀蛙」，携带详情显示变异标签，六项资质按倍率提升。

**为什么：** 先验证「抓到极品」的规则和反馈，下一张再做颜色区别，避免概率逻辑与动画问题同时发生。

## 玩家看到的效果与规则数值

- 抓取**成功后**独立按 **2.5%** 判变异；失败不判、目标被打死不判。宝宝也可以变异。
- 先按普通/宝宝既定规则生成六项资质，变异时六项分别 **乘 1.18 → 四舍五入**，**不再固定封顶**（旧 130 已废弃）。
- 变异不增加成长，不改变五项基础属性总点数及分配，也不影响当前战斗面板。
- 抓取成功日志和携带列表、宠物详情显示「变异」标记，并与相同个体永久关联，跨召唤、重开战斗保持；刷新网页按现有规则清空新抓宠。
- 正常预览严格保持 2.5%，另提供仅本地开发或单元测试使用的固定变异样本，不把「必出」逻辑带入普通模式。

## 华周怎么验收（一轮试玩）

在 Codex 提供的本地测试预览中抓到固定变异汀蛙：看到抓取成功提示、携带列表和详情上的「变异」；关掉详情再打开或「再来一场」，标记不丢。是否出现变异由固定测试样本核验，不要求靠 2.5% 自然刷出。

## 可调参数

mutation.rate=0.025、mutation.multiplier=1.18；**无 mutation.cap**；成长和五项基础属性配置不变。

## 逻辑测试

抓取失败时不触发变异随机判定；成功时恰好抽一次；随机边界值可控制普通/变异；宝宝与变异可叠加；六项倍率、四舍五入及新上限边界正确且不被旧 130 截断；成长及五项点数在变异前后完全不变；跨战斗资料保持；抓取测试回归通过。
