## 2. 玩家看到的效果和规则

从城镇预览「出城」后，野外增加一个显眼的**“固定开战（测试）”**入口。点它记录当前人物脚底世界坐标，清掉行走目标，再进入现有战斗；只开一场，不因站立或走路随机遇怪。本卡可在野外开关自动战斗，并显示当前状态。战斗仍使用现有三物种遭遇、当前进度、原战斗背景及操作；不创建第二份存档或奖励账本。

| 结果 | 判定与返回 | 经验、宠物与恢复 |
| --- | --- | --- |
| 击败最后一只 | `victory`，回开战前野外世界位置，镜头按该位置夹边，停步 | 原有整场经验只发一次；现有抓宠和出战选择保留；回图显示胜利与经验消息 |
| 抓走最后一只 | 也是 `victory`，回野外原位置，停步 | 抓到的宠物保留；按现行胜利规则发一次经验；抓非最后一只仍在本场继续 |
| 存活人物有效逃跑 | `escaped`，整队立即按既有离场时点撤离，回野外原位置，停步 | 不发整场经验；已成功保存的此前抓宠保留；无逃跑概率或费用 |
| 全队战败 | `defeat`，回城里出生点，停步 | 不发整场经验、不扣资源；此前成功保存的抓宠不回滚；人物和携带宠气血/法力回满 |
| 单宠「撤退」 | 只处理本场单宠退场/召唤 | 不当成人物逃跑，不直接返回地图；人物倒地不能发新的逃跑指令 |

新增**明确的结果原因** `victory/defeat/escaped`（可用等价命名），不要由 `winner` 或日志文字倒猜逃跑。每场新战斗按旧规则满血满蓝；城镇显示满血满蓝，不增加野外跨场续航或战斗中途存档。胜/抓胜/逃回野外后的 **180 世界单位保护距离**由 P2-05 的暗雷卡接入；本卡只保留一次性“战后返回”上下文，不能伪称已实测保护距离。

战斗动画播完，停止计时和自动调度，把同一场的结果及现有经验、抓宠、出战选择写入共用进度；**保存成功才返回地图并显示系统消息**。保存失败留在当前结果页，明确提示并给“重试保存”；只重试同一个候选，不重新判胜负、不重抽野怪/奖励、不再发经验，不能因为关闭弹窗、后台切回或重复回调绕过失败。对于本场非终结抓宠沿用现有即时保存时点；如果保存失败，不能冒充“已保存”，最终回场仍须以结算保存成功为前提。存档读取失败沿用原保护，不用新档覆盖旧档。

自动状态放在**当前会话**：野外可开关；开战沿用该值，开启时自动下达原有指令；战斗中改成关闭或开启后，下次固定开战沿用**最新选择**，不恢复开战前的快照。刷新沿用现有默认关闭行为，不增加自动设置持久字段。回图不会自动走路。此处只验证固定入口的跨场自动，随机暗雷衔接留 P2-05。

固定入口只随 `townPreview=1` 开发预览出现。正常启动仍进原有直接战斗，并保留其“再来一场”入口供旧玩法回归；**由地图进入的战斗**结束后改用地图系统消息，不显示“再来一场”。P2-05 正式入口切换时再移除普通入口的重开闭环。不要拿旧 `babySample`/`mutationSample` 开关替代同档地图验收。

**为什么这样做：** 固定开战把返回点、保存和胜败四条路径先测明白；随机遇怪只需在 P2-05 调用已验收的入口，战斗不会和步数逻辑同时改。

## 4. 逻辑测试与一次试玩

### 4.1 开发负责的测试

1. 存活人物逃跑得到 `escaped`，整队离场、敌人不继续攻击、无经验；人物不能用单宠撤退，宠物不能用人物逃跑。单宠撤退后本场继续，人物倒地不能再发逃跑。
2. 抓非最后一只继续；抓走最后一只为胜且原经验发一次。普通击杀胜与全队战败分别返回正确区域；胜/逃保留记录的世界位置，败回城出生点；四条路共用原 `SessionProgress`，已保存抓获在逃/败后仍在。
3. 播放事件完成前不切图；结算保存成功只执行一次。故意让存储写入失败，仍停在同一候选，重试成功后只返回一次、经验/抓获/出战 ID 不重复或丢失；连点、重复回调和后台切换不能绕过保存。
4. 地图和战斗切换不销毁正在复用的地图进度/世界位置；自动开/关进入本场、战斗中修改后的下一场取最新值；刷新不持久保存开关。旧直接战斗入口及其重开保持。

沿用 `node:test`，限定 `tsc` 覆盖新增纯逻辑及真实传递依赖。Cocos 节点、输入、动画回调和实际存储失败提示还须浏览器操作，不能由纯单测代签。

### 4.2 华周可照着点的一次试玩

开发交付 `townPreview=1` 的完整 URL 和正常启动 URL，准备**固定验收样本**：携带有空位、野外有一个标记的可达落脚点；可选单敌固定随机序列用于抓最后一只，另备两敌样本用于抓非最后一只；战败样本用固定等级/伤害或确定性输入，不能要求华周随机等怪或长时间练级。样本的角色/宠物属性、随机序列与启用方式在报告写清；仅在明确选择样本时使用，不静默覆盖正式存档，不引入隔离测试进度。

1. 城镇预览出城，走到可辨认位置，点「固定开战（测试）」。手动打赢，等动画结束，看见胜利和本场经验消息，返回原野外位置；角色不继续走。再开宠物/人物面板，经验及出战选择仍在，刷新后按现行规则回城并保留进度。
2. 从野外固定开战，用两敌样本抓非最后一只：仍留战斗；结束战斗后抓获宠物仍在。另以单敌样本抓走最后一只：胜利消息、一次经验、回原野外位置，抓宠与经验刷新保留。
3. 固定开战点人物「逃跑」，整队撤离，回原野外位置，无本场经验。再用宠物「撤退」，应仍在战斗，可召另一宠；以确定性战败样本输掉后回城出生点，气血/法力满、不扣已有进度和资源。
4. 在野外开「自动」再固定开战，确认自动出手。战斗中关自动，本场结束后仍为关；再开一场不自动。反向从战斗打开自动，下场自动打；地图不自动行走。
5. 开发用可复现的存储写入失败样本演示一次：动画后停在结果页并提示“保存失败/重试保存”；解除故障重试只落同一结果一次，刷新资料无重复经验/宠物。正常启动仍能直接开战并使用原“再来一场”。

开发须先在本机浏览器逐步实际点验，再交华周最终试玩。按当前构建口径记录主包、battle、town、outskirts、总包字节以及与起始提交的差值；未构建或微信模拟器/真机未操作均标 `NOT_TESTED`，不得把旧包体或开发自评写成实测。`qa` 对最终完整 SHA 的 diff 只读静态审查，重点看一次结算、写失败、视图节点和旧入口；QA 不跑测试或另写用例。
