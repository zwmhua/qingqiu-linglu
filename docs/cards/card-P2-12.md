## 1. 基线与三问

策划核对主线 `6c4cdc65916aa96d45ed2a4b14d4a68c7b62cd09` 已包含 P2-11 打书、天生技能顶替及城野切换出战。当前 `STATUS.md` 尚未登记 P2-11 最终验收。若华周已试玩通过，补登实际验收 SHA 后按卡序开工。规则依据为 `docs/phase2-design.md` §6.1、§6.2、§8、Q08、Q09 及 P2-12。

- **真实目标**　玩家能用对应露水把一只未出战的宠物洗成 0 级宝宝，确认前知道会失去什么，保存后可查看完整新资料。
- **可以砍**　复用背包选道具、选宠和二次确认，结果用原宠物面板展示。洗点、锁词条、保底、合宠另按后续需求。
- **最可能出错**　把还童资质按自然宝宝上半段抽、在变异旧值上重复乘倍率，或初始汀蛙还童后因旧来源规则读档失败。

## 2. 操作与规则

城里或野外打开背包 → 选择露水 → 选择携带宠 → 点「还童」→ 二次确认。确认框指明用哪种露水、消耗 1 个、目标宠，以及等级、经验、潜能、五项、资质、成长和技能会重置。确认前不抽随机、不扣材料，也不显示预抽结果。

| 输入 | 可选对象 | 结果 |
| --- | --- | --- |
| 还童露 `rejuvenation` | 普通、未出战的携带宠 | 同一只宠变成普通 0 级宝宝 |
| 变异还童露 `mutation-rejuvenation` | 变异、未出战的携带宠 | 同一只宠变成变异 0 级宝宝 |

- 已是宝宝也可再次还童，仍需对应露水和确认。战斗中背包只读。战斗、待保存、缺材料、身份不匹配、当前出战宠及目标已失效均拒绝，给出对应原因。
- 查实际出战 ID `SessionProgress.selectedPetId`。要洗当前出战宠，先在地图宠物面板把另一只设为出战，再回背包。
- 每次重新生成等级 0、经验 0、潜能 0、`isBaby=true`，五项系统随机分配合计 50，每项至少 1。保留同一 ID、物种、变异身份、名字、来源和现有来源标识。还童后的升级按宝宝规则。
- 资质和成长从当前物种的**完整配置范围**重抽，复用现有抽样及取整。自然宝宝仍使用上半段。变异从未乘倍率的新资质起算，只乘一次现有变异倍率并按原规则取整。成长不乘变异倍率，反复还童也按该流程生成。
- 技能重抽使用该物种现有自然技能生成规则，含生成时的必带项与原变异规则。雷击术、火球术按既有书限定范围处理。原技能会随重置替换。按现有公式重算基础缓存和有效面板，气血、法力以新上限回满，法力仍沿用现有计算和显示。保存成功后，若旧自动指令记住的法术已经不在该宠技能中，清除那条失效记录。

## 3. 原子保存与来源兼容

确认时重查地图状态、当前库存、携带宠、身份及实际出战 ID。同一个确认最多执行一次。通过后构造新宠和减去 1 个对应露水的库存，复用 `progressSnapshot` 同一次写入原主档。写成功才更新内存与界面；写失败显示原因，保留旧宠、库存、出战选择和原主档字节。取消不抽、不扣、不写。

本卡沿用 v5 字段。当前 `local-progress.ts` 把 `origin=initial` 限为普通非宝宝汀蛙。仅在当前 v5 允许合法 initial 普通汀蛙成为宝宝，仍完整检查初始 ID、物种、变异身份、技能、点数、等级与缓存一致性。其后即使宝宝升级，来源还是 initial。历史 v1～v4 校验、迁移、备份及现有宠物数据沿用原口径。当前 v5 继续读取 P2-11 已顶掉必带技能的其它宠。

**版本取舍**　现有 v5 字段已能表达还童结果，本卡只调整来源校验。新增合成来源与 ID 的版本处理放在 P2-13。

## 5. 测试与试玩验收

**逻辑和存档**

1. 固定随机序列覆盖完整范围上下界，验证还童能抽到自然宝宝下限以下，同时自然宝宝上半段及捕获逻辑不变。覆盖普通、变异、已是宝宝的重置成 0 级，五项随机合计 50、潜能 0；同随机输入重复变异还童，两次资质一致且只乘一次倍率，成长等于本次基础成长。
2. 错露水、无库存、无宠、已出战、战斗、待保存及取消均零消耗、零随机、零保存。确认后若改了实际出战宠，执行时再次检查。重复确认只应用一次。
3. 写入抛错时完整旧档、宠物和库存一致，UI 有提示。成功时一条写入携带宠和库存。普通初始汀蛙与变异捕获宠都能刷新读回并保持原 ID 与来源，初始还童宝宝随后升级也能读回。核对其他宠、背包项、选中出战以及现有迁移回归。

**本机 ego-browser**　用确定性样本备齐露水、普通初始后备汀蛙和变异捕获后备宠。随机序列和写入故障只由明确选择的验收样本注入，实际操作走游戏背包。

| 实际操作 | 预期效果 |
| --- | --- |
| 城里用普通还童露选一只非出战初始汀蛙，先取消，再确认 | 取消前后资料与数量一致。确认后少 1 个，道具提示成功，原 ID 的汀蛙变成 0 级宝宝。刷新后从宠物面板读到同一结果。 |
| 野外用变异还童露洗非出战变异宠，用同序列再洗一次 | 仍为同一只变异宠。两次均显示新属性和技能，固定序列的资质一致，倍率不叠加。刷新后保留。 |
| 错露水、选当前出战宠，战斗中打开背包 | 分别看到身份或出战提示，战斗为只读；库存和宠物均保持。 |
| 注入一次保存失败并确认，再解除故障重试 | 首次提示失败，旧档与内存一致。新一轮确认成功后，刷新核对只消耗成功的 1 个，并保留新属性。 |
