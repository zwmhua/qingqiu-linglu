# 青丘灵录｜02b-3｜汀蛙成长生成与显示

## 目标

玩家在宠物详情中看到每只汀蛙的三位小数成长，关闭页面或换场后成长不改变。

**为什么：** 成长跟物种走，同一种宠只在小范围有差异；目前只做汀蛙，其他物种以后分别配置，不用一套大范围混用。

## 玩家看到的效果与规则数值

- 在汀蛙物种配置写 **growthMin=0.882、growthMax=0.918**。普通汀蛙在闭区间内均匀抽取千分位整数，再除以 1000。
- 宝宝只在上半段 **0.900–0.918** 抽取；成长显示始终保留 **3 位小数**。
- 成长独立属于每只宠物，记录在内存实例中，查看详情、抓取、召唤、战斗重开不重新随机。
- 成长不参与气血、攻击、防御、速度等面板结算；变异不提升成长（变异留后卡）。
- 既有两只初始汀蛙也属于本物种普通 1 级个体，每只会话初始化时各生成一次成长，不是 0 级宝宝的成长区间。

## 华周怎么验收（一轮试玩）

在携带列表打开一只汀蛙详情，看到「成长 0.xxx」三位小数，范围在 0.882–0.918；打开另一只再回来，第一只数值不变；打一场再点回详情仍一样。宝宝上半段及端点由逻辑测试验证，不要求随机刷出宝宝。

## 可调参数

每物种 growthMin/growthMax；汀蛙 0.882/0.918，千分位精度 3；禁止恢复先前所有物种公用成长范围。

## 逻辑测试

普通取值在 [0.882,0.918]（含端点），宝宝在 [0.900,0.918]（含端点）；千分位离散值和三位小数显示；同一实例重复访问和跨战斗不变；随机源可控；基础面板属性不变；战斗、抓取、召唤回归正常。

## 本卡不做

不做其他物种成长、不做五项基础属性、变异、等级成长或属性换算，不重新设计宠物详情界面。
