## 1. 基线与三问

发卡基线 `01c4324abb895754d673aaa7e2c018c2dc18fb20`，已包含 P2-08 和战斗表现 v2 验收提交 `2e42feb95082bb8dd613dae1a3cac08e7c4aef51`。依据为 `docs/phase2-design.md` §3.3、§4、P2-09，以及项目 `AGENTS.md` 的阶段二执行口径。

- **真实目标**　学过主动法术的灵宠可以手动或自动施法，玩家能看清耗蓝、命中与耗尽后的普攻。
- **可以砍**　复用「灵术」入口、现有选敌和施法动画。三术共用一个单体结算，只用技能名与简单色调辨认。
- **最可能出错**　点选时提前扣蓝、连同物攻反应一起结算，或让播放中的蓝条提前显示后续动作的余量。

## 2. 定稿规则

| 项 | 规则与玩家可见效果 |
| --- | --- |
| 技能 | 雷击术、火球术、水箭术，单体敌方目标。每次消耗法力 5，读取现有 `PET_SKILLS` 参数。三术共用公式。 |
| 法伤 | `L=max(1, 真实等级)`。伤害为 `max(1, round(6 + 2×L + 攻方灵力 − 0.5×守方灵力))`。按确定值结算，不抽法伤随机。 |
| 命中 | 绕过物理防御姿态、保护分摊、硬甲及物理被动。复用已有扣血、倒地、胜负与经验入口。战斗事件带命中血量快照，接现有施法播放。 |
| 手动 | 轮到灵宠时点「灵术」，列表只列它已学的主动法术和耗蓝。选择技能，再点存活敌方目标；取消列表或选敌可回到指令。有法术但蓝不足时说明原因，无主动技能时也给出提示。人物继续用既有指令。 |
| 扣蓝 | 仅实际施放时扣 5。取消、倒地或离场、无合法目标、战斗提前结束均不扣。执行时蓝量不足，沿用现有普攻目标处理并提示「法力不足，改为普攻」。 |
| 法力周期 | 同场换下再召回保留余蓝，新场和回城按现有规则回满，升级补满沿用原规则。宠物状态卡和面板读本场当前／最大法力，地图展示满值。 |
| 自动与敌方 | 野怪、玩家自动灵宠在执行攻击时选技能栏中第一个已学且付得起的主动法术，否则普攻。沿用双方原有随机存活目标和出手排序。玩家已有的自动防御指令、人物自动指令和超时补普攻照旧。 |
| 来源 | 使用当前 `skillIds`。水箭术沿用现有物种池。雷击术、火球术维持既定打书来源，验收通过隔离样本预置三术。 |

本轮范围到单体法术、当前法力和自动规则为止。群体法术、元素克制、冷却、法暴、独立法防、人物学习、打书玩法和新资源由各自需求承接。

**实现建议**　把法术选择和伤害计算留在纯逻辑，共用同一套规则。野怪只从已有宠物属性公式补最大法力、灵力，气血和物攻等继续取 `wildCombat` 与既有被动结果。复用现有 `kind: 'spell'` 回放形状和光效，按本次施法的快照显示蓝量与命中血量。法力余量只随本场单位存在。

## 4. 逻辑验收

1. 三术共用耗蓝与公式，覆盖 0 级按有效 1、舍入和最低 1 点。带硬甲、处于防御或由另一单位保护的目标照公式扣血，施法方和守方均不触发物理被动。
2. 预置 5 点法力可施放一次到 0；4 点提示且仍为 4。未学技能和人物不能提交施法。施法前取消、先倒地、离场、没有目标、原回合提前结束时保持原法力。覆盖合法指令提交后执行时蓝不足，按原普攻处理。
3. 验证同场换下／召回保持余蓝，开启新战斗重新回满。检查自动与野怪先选首个付得起的主动法术，蓝少于 5 改普攻，旧自动防御保持。固定随机源核对目标路径和无额外抽签。
4. 回放本击才更新蓝量和目标血条，回放清空后正常开下一回合或正常结束，法术终结照常判定一次。现有 P2-08 同击、连打、抓取和状态桥接测试保持通过。

## 5. 华周试玩

用支持 `PREVIEW` 与 `devPreview=1` 的原预览路径，复用隔离样本。执行报告给实际可打开的 URL、样本入口和准备步骤。用固定 10 级出战宠与 10 级目标，样本不依赖正式掉落或随机抓宠。伤害对照可取攻方灵力 24、守方灵力 20，照公式每次 **40**。

| 样本 | 操作和可见结果 |
| --- | --- |
| 手动与三术 | 人物防御，宠物点「灵术」，依次试三术。先打开列表或选敌后取消，法力保持。再实际命中，能区分三术表现；每术同伤害、各耗 5。用同资料带硬甲对照。 |
| 恰好／不足 | 用蓝量 5 和 4 的预置样本。5 点能施法一次变 0；4 点提示不足。切到一只没有主动技能的宠，能看到原因；人物也仍按原有指令操作。 |
| 余蓝与自动 | 用能施法两次的样本，耗一次后换出再召回，检查余蓝。打开自动，分别观察己方宠与有技能的野怪，有蓝时用法术，耗尽后普攻。结束战斗并开下一场，核对回满。 |
| 播放收尾 | 用 ×1 和 ×2 各完成一场，核对蓝条在施法过程中更新、命中时扣血，并可继续下指令或正常回地图。 |
