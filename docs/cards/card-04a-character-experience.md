# 青丘灵录｜卡 04a：经验结算与人物升级

**状态：策划终稿 v1.1｜未授权开发。**  
**前置：** 卡 03a、03b 已由华周试玩通过；卡 04 总规则已定。  
**目标：** 0 级撷灵客打赢获得经验，能够升级并自动增加五项与潜能；玩家能用**最小文字信息**看到升级结果，浏览器刷新后进度保留，测试重置可重来。  
**风险：qa**（本地进度读写与测试重置）。  
**本卡只验收人物升级，不制作 04b 的完整人物加点面板，也不给召唤兽经验；召唤兽经验留 04c。**

## 一、范围与玩家看到的效果

1. 全新开局的人物为「撷灵客」真实 **0 级**、五项各 10、潜能 0、经验 0；0 级仍显示 0，战斗按有效 1 级，人族系数直接换算出气血 50、法力 30、伤害 7、防御 15、速度 10、躲避 10、灵力 16。初始气血/法力为满。
2. 初始化**两只互相独立随机 1～5 级**普通野生汀蛙（非宝宝非变异），各自资质/成长/五项按该等级现有规则生成，战斗使用该等级的汀蛙临时面板，取消旧固定 `38/11/10/10`。本卡只初始化及保留资料，不给它们升级或加点。
3. **最小升级界面**：战斗中或结算后提供一个轻量「人物进度」文本区/简报，至少清楚显示「等级」「本级经验 `当前/所需`」「五项当前点数」「剩余潜能」，以及按人族系数换算并四舍五入后的「当前/最大气血」「当前/最大法力」「伤害」「防御」「速度」「躲避」「灵力」。胜利结算显示「本场获得经验」，升级时明确显示「五项各 +1、潜能 +5」。这是 04a 的最低可视验收，不得用“已存在内存数据”代替显示，也不提前做 04b 左右分栏完整面板和 `＋/－/确认/取消`。
4. 战斗胜利时人物获得经验，足够则一次或连续升级；五项自动各 +1、未分配潜能每级 +5，未分配潜能仅显示，不开放加点。升级后当前气血/法力补满新上限；下一场以新上限满值开始。
5. 使用本游戏浏览器本地进度（`localStorage`）：保留人物等级、经验、五项、潜能；也保留两只汀蛙及现有携带个体的 ID、物种、**真实等级**、五项、六资质、成长、宝宝/变异身份，以及携带名单与当前出战选择。刷新不会重抽等级或重掷个体资料。04b、04c 沿用同一份进度。
6. 一个**测试用「重置」按钮**（须确认）：只清除本游戏测试进度，回到 0 级撷灵客和两只新随机 1～5 级普通汀蛙；取消重置则所有进度不变。

## 二、规则与数值（全部已定）

**单级经验：** `levelUpExp(L)=10×(L+1)`，0→1 需 10、1→2 需 20，依次递增至 19→20 需 200；20 级封顶。经验超出当前需求时扣除本级需求并连续升级；20 级不再保存超额经验。

**本场经验：** 战斗开始时记录所有初始敌人，每只贡献 `8+2×max(1,敌人等级)`；整场胜利经验求和。0 级宝宝与 1 级野怪各 10，2/3/4/5 级分别 12/14/16/18。战败 0；被抓取的敌人也计入胜场经验，抓住不额外奖励；同一场只能结一次。撷灵客倒地但整队获胜也发全额。

**人物升级：** 五项各自动 +1，剩余潜能 +5；人族五项换算系数与总卡完全一致，不照搬旧人物面板数字。0→1、尚未手动分配时：五项各 11、潜能 5；气血 55、法力 33、伤害 7、防御 17、速度 11、躲避 11、灵力 18。

**经验资格接口：** 04a 先建立共用的奖励/参与资格规则，人物领经验；04c 再接入实际出战召唤兽各领全额经验，不在 04a 偷做召唤兽升级。

## 三、华周一次试玩怎么验收

1. 点测试重置并确认：人物**显示 0 级、经验 0/10、五项各 10、潜能 0**；轻量进度里能看到当前/最大气血 50/50、当前/最大法力 30/30、伤害 7、防御 15、速度 10、躲避 10、灵力 16。初始两只汀蛙各在 1～5 级，按各自等级计算五项总点数与临时面板。
2. 打赢一场，在结算看到本场经验；确认人物等级/本级经验变化。继续打至升级，**肉眼看到**升级提示「五项各 +1、潜能 +5」，等级 0→1，五项各 11、潜能 5，当前/最大气血及法力补满新上限，轻量进度显示气血 55、法力 33、伤害 7、防御 17、速度 11、躲避 11、灵力 18。
3. 打有抓取行为的一场并最终获胜，被抓目标仍算整场经验；战败一场，经验不加。重开战斗不得重复领同一场经验。
4. 刷新网页，人物已得经验、等级、潜能，以及初始两只汀蛙的真实等级与个体资料都保留。点重置后**取消**，进度不变；重新点重置后**确认**，人物回 0 级、重新生成两只随机 1～5 级汀蛙。
5. 04a 无加点按钮和完整左右分栏是**正确范围**；04b 再验收完整人物面板。

**试玩判断：** 人物是否真的从战斗获得经验并升级？看得懂每升一级得到什么？初始难度是否可接受？
