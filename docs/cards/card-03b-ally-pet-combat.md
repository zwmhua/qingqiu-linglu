## 一、目标

抓到汀蛙、磐龟或毛毛虫后，使用已有「召唤」让它上阵，**己方抓获宠**按物种和有效等级使用与敌方一致的临时气血／攻击／防御／速度；跨战斗保留身份和数值。**唯独初始两只 1 级普通汀蛙保留 38/11/10/10。**

**为什么：** 03a 已让三种怪能遇见、能抓、能看资料。03b 只验证「抓到的宠是否真的能按自身特点战斗」，不给同一张卡再加入升级和永久成长公式。

## 二、玩家看到的效果与规则

1. **复用已有召唤。** 在携带列表中找到抓到的磐龟或毛毛虫，按现有操作召唤上阵；名称、图片、等级、宝宝／变异标记仍正确。单场只能有一只己方宠物上阵，不修改原召唤次数、目标、速度次序或切换规则，不增加新选择入口。
2. **敌我共用临时面板（临时，待公式卡替换）。** 对抓获的三物种宠物，令 `d = max(1, level) - 1`，使用与 03a 敌方相同的既有配置和计算函数：
   | 物种  | 最大气血      | 攻击                | 防御               | 速度                |
   | --- | --------- | ----------------- | ---------------- | ----------------- |
   | 汀蛙  | `33 + 4d` | `10 + floor(d/2)` | `9 + floor(d/2)` | `9 + floor(d/2)`  |
   | 磐龟  | `45 + 6d` | `9 + floor(d/2)`  | `13 + d`         | `7 + floor(d/2)`  |
   | 毛毛虫 | `26 + 3d` | `14 + floor(d/2)` | `7 + floor(d/2)` | `10 + floor(d/2)` |
   **1 级实例：** 汀蛙 33/10/9/9，磐龟 45/9/13/7，毛毛虫 26/14/7/10。\
   **5 级实例：** 汀蛙 49/12/11/11，磐龟 69/11/17/9，毛毛虫 38/16/9/12。
3. **唯一起始例外。** 开局自带的两只普通 1 级汀蛙，无论是否互相切换、是否跨战斗，都保持 **38/11/10/10**。抓到的野外汀蛙**不属于**这个例外，使用上表对应等级的面板。不能仅凭物种名判断是否为初始宠，应沿用已有个体来源身份。
4. **0 级宝宝。** 详情与战场仍显示 `Lv.0`，计算面板用有效等级 **1**；不改变其真实等级或五项基础属性的 50 点总额，不提前做 0→1 升级。
5. **继承和恢复。** 已抓宠的物种、等级、六项资质、成长、五项基础属性、宝宝／变异状态不因召唤、退场、再来一场而重掷。**同场抓获后的当前残血**按已有机制保留；**进入下一场满血恢复**按现行规则执行，最大气血必须与对应物种和等级的临时公式一致；不得把当前残血误当最大气血。
6. **仅战斗差异，不做正式养成换算。** 变异加成继续只影响六项资质，不改变临时面板；成长和五项基础属性仍只展示、不参与气血／攻／防／速计算。抓取满血基础率 20%、5% 宝宝、25% 出场变异、倒地改抓以及随机遭遇规则一律不动。

## 三、华周怎么试玩（一次浏览器试玩会话）

1. 打开 Cocos Web 预览，抓一只**磐龟**，在已有「召唤」列表中让它出战。看名称、图片、等级正确；相同等级下，它应比汀蛙血厚、防高、速度慢。不要只看图片，观察血条和实际攻击／承伤／行动顺序。
2. 再抓一只**毛毛虫**（携带上限为 5，初始已有 2 只，注意剩余容量），召唤上阵。看它比同级汀蛙攻击更高、生命更少；没有变成汀蛙的战斗数值。
3. 用已有两只**初始汀蛙**互相切换，确认仍沿用原来的战斗体验和 **38/11/10/10**；抓来的汀蛙与初始汀蛙不同，不能误享受初始数值。
4. 按「再来一场」后重新召唤前面抓到的宠：物种、等级、宝宝／变异、资质、成长和五项点数保持；宠物按原有规则满血恢复、上阵数值正确。**不要求抓获宠自动成为下一场默认上阵**，仍使用当前召唤入口。
5. 0 级宝宝和 5 级边界不要求靠随机手刷。Codex 用现有测试随机源提供可复现测试证据；如原有预览测试机制可安全显示样本，可在本地预览检视，但不得改变正常概率。

**判断是否继续：** 换上磐龟／毛毛虫后，是否能实际感受到“更耐打／更能打”，而不仅是图换了？试玩结束记一行：\`日期｜03b｜好玩／不好玩／手感不对｜原因\`。**数值手感不合适需由华周决定后续单点调整，不能在本卡自行改已拍板数值。**

## 五、逻辑测试（必须，不得写“无”）

1. **敌我一致：** 构造三物种抓获宠，测试 0／1／5 级的最大气血、攻击、防御、速度与同物种敌方 `wildCombat` 相同。覆盖抓取后同场召唤、跨战斗重建以及再次召唤。不得仅对比显示文本。
2. **初始例外：** 两只 `origin=initial` 的汀蛙一直为 38/11/10/10；\`origin=captured\` 的 1 级汀蛙为 33/10/9/9，不因为同名被当初始宠。
3. **宝宝边界：** `level=0`、\`isBaby=true\` 不变，但战斗面板按 1 级计算；0 级宝宝五项总点数仍为 50。
4. **身份及数值稳定：** 召唤、切回、下一场重建后保留 species、level、isBaby、isMutated、aptitudes、growth、baseStats 与最大气血、攻、防、速。变异不额外改变临时面板；同场残血处理、换场满血恢复沿用现行规则。
5. **既有回归：** 抓取、满 5 只拒抓、倒地改抓、出场时 25% 变异、5% 宝宝、敌方 1～3 只的随机遭遇、速度结算、攻击／防御／保护和召唤均不退化。沿用仓库现有可运行的 `node:test` 测试；不得为了本卡安装依赖。若改 `assets/logic/`，必须有对应纯 TS 规则单测。

**实现提示：** 目前 03a 代码可能已在抓取时复制了敌方的临时面板；**先跑针对性测试**。若己方面板已经正确，尽量只补必要的回归测试和证据，不重写战斗或另造第二套计算函数。已有规则在一场内保留残血、跨战斗恢复满血，测试须按当前机制区分。
