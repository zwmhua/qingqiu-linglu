## 2. 资格与属性

| 项 | 定稿规则 |
| --- | --- |
| 使用条件 | 城里或野外。两个不同 ID、都在携带中、等级均至少达到配置 10、均非出战，变异身份相同。合宠不耗书、露水或货币。 |
| 等级与经验 | 新等级 `floor((A.level + B.level)/2)`，上限沿用当前 20 级，新经验 0。 |
| 物种 | 异种父宠 45% A、45% B、10% 其它。同种为 90% 原物种、10% 其它。其它从已启用且不同于两亲的物种等概率选。其它池为空时提示配置错误并禁用合宠。 |
| 六资质 | 每项各抽一个均匀倍率 `[0.70, 1.10]`，乘双亲该项实际值的均值，最后四舍五入为整数，并按结果物种资质上限封顶。变异上限为 `round(普通上限 × 1.18)`，倍率读现有配置，双亲实际值不再乘变异倍率。 |
| 成长 | 双亲实际成长均值 × 独立均匀倍率 `[0.96, 1.02]`，保留 3 位小数，按结果物种上限封顶。资质和成长保持正值即可，均可低于物种通常下限。 |
| 身份与五项 | 普通＋普通仍普通，变异＋变异仍变异。任一父宠为野生，结果为野生，`50+10L` 点由系统分完、潜能 0。两亲均为宝宝，独立随机基础 50，每项加 `L`，潜能 `5L`。每项基础点至少 1。 |
| 来源与携带 | 新宠使用全新 ID、来源 `fused`，重算基础面板。保存成功后父宠移除一对，新宠加入，携带总数减 1；原出战宠保持，查看对象切到新宠。 |

### 技能遗传

先纳入结果物种的必带技能，并从每只父宠现有技能里去掉该父宠所属物种的必带项。余项合并去重，与结果必带重复的再剔除。对每项独立抽 **40%**。若命中多于剩余格，均匀无放回随机取至 `8−结果必带数`。例如磐龟天生硬甲不遗传给汀蛙，汀蛙打书学到的硬甲可遗传。父宠通过打书获得的非必带雷击术和火球术也按此规则。合宠只取结果必带与父宠遗传，不另外抽物种池或额外加变异技能。结果必带数超过 8 属配置错误。

## 3. 操作、原子保存和 v6

- 城野点「合宠」打开时停步，挡地图点击与遇怪。左、右分别选宠，显示物种/名字/等级/身份、现有图、六资质、成长、技能格。中间为丹炉占位和「合宠」。展示物种概率、遗传率及可能变弱的提示。城里丹炉台和地图按钮共用入口，战斗中及结算待保存时禁用。
- 二次确认明确提示“两只原宠将消失，结果可能变弱”。确认前只显示规则；取消零生成、零写入。确认时重新验证两亲、出战选择、非战斗上下文及配置。同次确认拦截重复执行。
- 首次确认只生成一个候选。校验子宠点数、技能、属性、来源与 ID，构造将两个父宠替换为一个子宠的完整名单和新序号。沿用现有快照入口一次写入。保存成功才发布名单与序号、清理已移除父宠的自动记忆，并打开新宠资料；失败提示并保留双亲、出战引用、库存、序号和原档。同会话重试复用同一子宠与 ID 候选并重验资格，避免复用过期快照覆盖已变化的进度。失败时不揭示随机结果。
- **本卡采用 v6。** 新增 `origin=fused` 和独立递增序号（建议字段 `nextFusedId`、ID `fused-<n>`）。新序号与新名单在同一次保存里提交，删除旧合成宠、刷新或再次合宠时不会复用已发放 ID。当前版本升级须拒绝不合法的序号／来源或重复 ID。
- v1～v5 仍按各自原规则校验、备份和迁移。尤其 v5 的背包、结算 ID、还童后的 initial 宝宝、打书顶掉必带的技能及原捕获计数和出战 ID 原样延续，补合成序号后写入 v6。迁移失败保留旧档，成功刷新不重抽。
- 新 ID 明确纳入战斗与界面的宠物识别。验收新宠可在地图切换出战，刷新后进入下一场以正确的宠物立绘、技能和派生属性上场。

## 5. 测试与试玩

- **规则**　用固定序列覆盖 9/10 级、相同 ID、出战、混合变异、空其它池；核对 45/45/10、90/10、其它同权、资质/成长独立倍率及上下界、变异封顶、不托下限、宝宝与野生点数、按父母物种去必带、去重、40% 和满 8 均匀截断。
- **事务与迁移**　取消和无资格零写入、重复确认只写一次。故障注入时主档、双亲、出战与计数保持。重试不重抽，成功后再刷新对照。直接读取 v5 真样本（初始宝宝、顶掉硬甲的磐龟、已有库存），核对原数据；拒绝不合法 v6 ID/序号；二次合成与放生后 ID 递增。
- **ego-browser**　用显式固定样本，走正常入口。城里用两个非出战、10 级普通宝宝，汀蛙带连打/水箭术，磐龟带硬甲/还击。确认前看概率及风险，确认后看两旧换一新、五项合计 100、潜能 50、经验 0。将新宠设为出战后进一场战斗。野外用另外两只同种变异后备宠，验证停步、同种概率、变异身份和 v6 刷新。再试 9 级或出战拒绝、取消和一次保存失败重试。样本需保留另一只出战宠，固定注入仅用于验收入口。
