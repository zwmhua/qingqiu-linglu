# 青丘灵录 · AI 协作规则

1. 动手前先读 `docs/` 下的文档：`docs/roadmap.md`、`docs/cards/` 里当前要做的那张卡。
2. 一次只做一张卡，只做卡里「范围」写的内容，「不要做」的一律不做。
3. 名字、数值、概率以文档为准。文档没写的数值不要自己编，先停下来问我。
4. 所有名字原创，不要使用梦幻西游或其它现成作品的名字（如召唤兽、炼妖、兽决、大海龟等）。
5. 数值集中放在配置文件，规则逻辑和界面分开写。
6. 做完只说：玩家能看到什么、怎么试玩、哪些没实际运行验证过。没跑过的不要说通过。
7. 不要修改 `docs/` 里的文档，除非我明确要求。
